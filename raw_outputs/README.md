# Raw local solver outputs

The public repository currently contains the **locked scores, rubric dimensions, claimed/actual completion labels, statistical analysis, figures, methodology, and post-hoc repository audit**.

The twenty complete local solver transcripts (10 ATTICUS + 10 raw Sol) were produced across separate ChatGPT conversations. They are not included here yet as a normalized export because this publication pass does not have an authoritative machine-readable export of all 20 conversations.

This is a transparency gap, not an invitation to reconstruct or paraphrase the missing records. The scores and analysis should therefore be treated as auditable **derived data**, while full transcript-level independent regrading requires release of the exact solver outputs.

When an authoritative export is available, it should be added verbatim under this directory with hashes, without editing the mathematical content.

**The ATTICUS framework prompt/implementation itself must not be included with those transcripts.**
